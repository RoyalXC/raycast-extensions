# Time Transfer Changelog

## [1.0.2] - 2026-10-13

### Added

- 显示具体转换错误原因，支持复制含错误项的原值 / 结果 / 状态对照表。
- 自动保存输入模式、时区、日期输出单位、复制后关闭窗口设置。
- 支持本地 / UTC 时区、日期输出秒 / 毫秒，以及精确保留小数秒。
- 增加模式切换快捷键、保持窗口连续复制和恢复默认设置。

### Improved

- 读取选中文本或剪贴板时增加 1.5 秒超时；选区已返回时无需等待慢剪贴板请求。

## [1.0.1] - 2026-10-13

### Fixed

- 统一无时区日期的本地时区规则，严格校验日期、时间与时区偏移。
- 修复负数、小数秒、前导零和八位早期时间戳的解析；提供显式单位和日期模式。
- 防止异步读取覆盖用户输入，转换结果与当前输入同步更新。
- 修正有效输入被误标为无效、功能描述与实际行为不一致的问题。

### Added

- 无选中文本时读取剪贴板，支持重新读取与批量转换、复制全部结果。
- 解析和输入读取的回归测试。

## [1.0.0] - 2026-01-21

### Added

- 支持将时间戳转换为中文日期格式（YYYY-MM-DD HH:mm:ss）
- 自动读取剪切板内容
- 支持从剪切板中智能提取多个时间戳
- 支持手动输入时间戳进行转换
- 转换结果自动复制到剪切板
- 支持毫秒级和秒级时间戳自动识别
