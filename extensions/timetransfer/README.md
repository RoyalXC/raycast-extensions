# Time Transfer

Raycast 时间戳与日期转换插件，支持手动输入、选中文本和剪贴板批量读取。

## 使用方法

1. 在 Raycast 中搜索「时间戳转换」或 `Time Transfer` 打开命令。
2. 打开时优先读取前台应用的选中文本；没有选中文本时读取剪贴板。开始手动输入后，迟到的读取结果不会覆盖输入。
3. 输入后立即展示转换结果。右上角可以选择自动识别、秒级时间戳、毫秒级时间戳或日期模式。
4. 按回车复制当前选中结果；多条结果时按 `⌘⇧C` 复制全部有效结果，每条占一行。默认复制后关闭窗口，可在操作菜单选择「复制后保持窗口」。
5. 按 `⌘⇧V` 重新读取剪贴板，也可以从操作菜单选择「从剪贴板读取」。
6. 按 `⌘⇧T` 复制原值、结果、状态三列对照表，可以直接粘贴到 Excel。无效输入保留空结果和具体错误说明。
7. 输入模式、日期输出单位、时区、复制后是否关闭窗口会自动保存，下次打开继续使用。操作菜单可以恢复默认设置。

### 常用设置与快捷键

- `⌘⌥1`：自动识别；`⌘⌥2`：秒级时间戳；`⌘⌥3`：毫秒级时间戳；`⌘⌥4`：日期模式。
- 操作菜单的「设置」中可以切换本地 / UTC 时区、日期输出秒 / 毫秒、复制后保持 / 关闭窗口。
- 读取超时为 1.5 秒：选中文本读取失败或超时会尝试剪贴板，剪贴板也失败时提示重试；手动输入始终可用。
- 选中文本已读取成功时直接展示，无需等待慢剪贴板请求；迟到的读取不会覆盖新的输入。

插件不会在打开或每次输入时自动写入剪贴板。

## 解析规则

- 无显式时区的日期使用当前选定时区，默认本机时区，也可切换为 UTC。窗口标题显示当前时区和日期输出单位。
- 带 `Z` 或 `±HH:mm` 的日期按输入指定的时区解析；时间戳转日期显示当前选定的本地或 UTC 时间。
- 支持 `YYYY-MM-DD`、`YYYY/MM/DD`、日期加空格或 `T` 连接的时间，例如 `2026-02-01 00:00:00`、`2026-02-01T00:00:00+08:00`。年月日和时间均严格校验，不会将 2 月 29 日自动改成 3 月 1 日。
- 自动模式下，所有纯数字按时间戳识别：绝对值小于 `100000000000` 为秒，否则为毫秒。符号和前导零不影响单位识别。
- `yyyyMMdd` 是有歧义的纯数字格式，只在「日期」模式下按日期解析。例如 `20230101` 在自动模式是秒级时间戳，在日期模式是 2023 年 1 月 1 日。
- 可用「秒级时间戳」或「毫秒级时间戳」模式明确指定单位，避免历史或远期时间戳被自动规则误判。
- 支持负数和精确到毫秒的小数秒，例如 `-1`、`1769875200.5`；毫秒输入必须是整数。超过毫秒精度、日期范围或不支持的格式会显示为无法转换。
- 日期转时间戳默认输出整数毫秒，也可改为秒；秒输出保留非零毫秒的小数，不做截断。时间戳转日期输出 `YYYY-MM-DD HH:mm:ss`，有非零毫秒时保留 `.SSS`。

## 批量转换

从选中文本或剪贴板读取时，支持换行、逗号、分号、制表符分隔的多条输入；中文逗号和分号也可使用。纯数字列表还支持空格分隔。日期和时间之间的空格会保留。

搜索框是单行输入：手动输入多条内容时使用逗号或分号；多行内容请用 `⌘⇧V` 从剪贴板读取，插件会将换行转成分隔符，保留每条日期的边界。

按输入顺序保留每条结果和重复项；无效输入单独列出日期不存在、时间无效、精度过高或超出范围等具体原因。复制全部有效结果时跳过无效项并提示数量；复制对照表时保留全部项及错误说明。不会从任意 JSON、日志或自由文本中猜测哪些数字是时间戳。

例如剪贴板内容：

```text
1769875200000
1769961600
2026-02-01 00:00:00
```

在 `Asia/Shanghai` 时区，`1769875200000`、`1769875200` 和 `2026-02-01 00:00:00` 对应同一时间。

## 开发

```bash
npm ci
npm test
npm run lint
npm run build
npm run dev
```

`npm run build` 重新构建本地扩展。首次使用需要在 Raycast「Import Extension」中导入源码目录。
